//===== Описание

Адаптивная вёрстка лендинга, созданная по макету. Проект выполнен с использованием Bootstrap 4 для сетки и UI-компонентов, а также jQuery для интерактивных элементов. Включает кастомный аккордеон и встроенную карту. Страница корректно отображается на всех популярных разрешениях экранов, включая мобильные устройства.

//===== Используемые технологии:

- HTML5 и CSS3
- Bootstrap 4 — адаптивная сетка и стили компонентов
- jQuery — реализация интерактивного функционала (аккордеон, работа с DOM)
- Встроенная карта через iframe
- Адаптивная вёрстка — через медиазапросы и возможности Bootstrap

//===== Основной функционал:

- Кастомный аккордеон на jQuery
- Встроенная карта (Яндекс.Карты)
- Адаптивная сетка Bootstrap
- Семантичная разметка
- Поддержка мобильных устройств
